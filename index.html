02. Модели:

03. Cursor / VS Code: Settings → Models → Custom / OpenAI-compatible → вставь Base URL и свой ключ sk-....

04. OpenCode: в конфиге добавь кастомного провайдера: baseURL = …/v1, apiKey = твой ключ sk-..., модель — одна из списка выше.

05. Python:

from openai import OpenAI
client = OpenAI(api_key="sk-...",
    base_url="…/v1")
r = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[{"role": "user", "content": "Hi!"}])
print(r.choices[0].message.content)

// Ошибка "code is invalid" = ключ вставлен не в то поле: нужен apiKey кастомного провайдера, а не стандартный OpenAI-ключ.
